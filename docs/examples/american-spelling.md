Use American spelling everywhere: organization, optimize, behavior, center, license, defense. Not the British forms.

**Why:** Asked for it directly after British spellings appeared in seeded README files (2026-08-09).

**How to apply:** Applies to committed documentation, code comments, and record text across all LumaStack projects — not just the repository where it came up. Watch the `-ise`/`-isation` endings in particular; they slip in most often.
