# Do not screenshot text

A picture is not cheaper than the words in it. A screenshot of your screen turns
into a few thousand tokens, and a 4K one closer to five thousand. That is a
great deal of text you could have pasted instead.

**So paste text instead.** It is cheaper, and there is a second reason that matters more
day to day: **your agent can edit text and cannot edit a picture.** Send an error
as a screenshot and the best it can do is read it back to you.

The exception is real and worth naming, so this does not become a superstition.
**When the layout is the thing you are asking about** — a rendered page, a chart,
a UI that looks wrong — the image carries information the text does not, and it
earns its cost.

For anything you could have selected and copied, it is a straight loss.  If you must
use a screenshot, consider having a subagent interpret the image to text for you.

## Takeaways

- A picture is not cheaper than the words in it — a screenshot requires a few thousand tokens, more at 4K.
- **Paste the text.** Cheaper, and your agent can actually edit text.
- Send an error as an image and the best it can do is read it back to you.
- If screenshots are unavoidable, consider using a subagent to interpret the image to text.
- **The exception:** when the *layout* is the question — a rendered page, a chart, a UI that looks wrong — the image earns its cost.
